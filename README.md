<h2><img src="https://raw.githubusercontent.com/smansfeldg/smansfeldg/main/assets/mark.svg" width="16" align="top" alt=""> &nbsp;About</h2>

I started on the **product side** — building e-commerce platforms end to end, arguing about button states and checkout flows. Then I moved to the **platform side**, and never really left either one.

That combination is the whole point of my profile. I know what a six-minute build costs a frontend team, and I know what a careless query costs a cluster at 3 AM. So I design infrastructure the way I'd design an interface: fewer steps, obvious defaults, no surprises.
